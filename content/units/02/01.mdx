## 생각 열기 — 이름이 없으면 다시 못 쓴다

계산기로 `88 + 92 + 75` 를 눌러 255를 얻었다. 그런데 이 값을 3으로 나눈 뒤, 다시 처음 세 수의 최고점과 비교하려면 어떻게 해야 할까. 계산기 화면에는 마지막 결과 하나만 남아 있다.

<InfoBox variant="think" label="함께 생각해 보기">
값을 **나중에 다시 쓰려면** 어딘가에 두어야 하고, 두었으면 **어디에 두었는지 가리킬 방법**이 있어야 한다. 사물함에 물건을 넣을 때 번호가 필요한 것과 같다. 프로그램에서 이 번호에 해당하는 것은 무엇일까?
</InfoBox>

## 변수 — 값을 담아 두는 이름

<Term ko="변수" en="variable" desc="값을 담아 두고 이름으로 꺼내 쓸 수 있게 한 저장 공간" />는 값을 담아 두는 상자에 붙인 이름이다. 이름을 알면 언제든 값을 꺼내 쓸 수 있고, 새 값을 덮어써 바꿀 수도 있다.

변수에 값을 넣는 일을 대입이라 하고 `=` 로 적는다. **수학의 등호와 뜻이 다르다.** 1단원 7차시에서 순서도에 `←` 로 적었던 그 화살표가 여기서 `=` 가 된다.

<CodeSample lang="python" caption="값을 넣고, 바꾸고, 맞바꾸기" expect={"처음 점수: 88\n고친 점수: 92\n바꾼 뒤 a = 20 , b = 10\n"}>
{`점수 = 88
print("처음 점수:", 점수)

점수 = 92
print("고친 점수:", 점수)

a = 10
b = 20
a, b = b, a
print("바꾼 뒤 a =", a, ", b =", b)`}
</CodeSample>

<CodeSample lang="c" caption="값을 넣고, 바꾸고, 맞바꾸기" expect={"처음 점수: 88\n고친 점수: 92\n바꾼 뒤 a = 20 , b = 10\n"}>
{`#include <stdio.h>

int main(void)
{
    int score = 88;
    printf("처음 점수: %d\\n", score);

    score = 92;
    printf("고친 점수: %d\\n", score);

    int a = 10, b = 20, temp;
    temp = a;
    a = b;
    b = temp;
    printf("바꾼 뒤 a = %d , b = %d\\n", a, b);
    return 0;
}`}
</CodeSample>

<InfoBox variant="tip" label="두 값을 맞바꾸려면 그릇이 하나 더 필요하다">
C 쪽을 보자. `a = b; b = a;` 라고 적으면 안 된다. 첫 줄에서 `a` 에 `b` 를 넣는 순간 원래 `a` 값이 사라지기 때문이다. 그래서 잠깐 담아 둘 `temp` 를 쓴다. Python의 `a, b = b, a` 는 이 과정을 언어가 대신 해 주는 것이다. **편해 보이는 문법 뒤에 무슨 일이 일어나는지 알아 두면 다른 언어로 옮길 때 막히지 않는다.**
</InfoBox>

## `=` 는 같다는 뜻이 아니다

수학에서 `x = x + 1` 은 성립하지 않는 식이다. 프로그램에서는 자주 쓰는 문장이고 뜻이 전혀 다르다.

> **오른쪽을 계산해서 그 값을 왼쪽 변수에 넣어라.**

그래서 `점수 = 점수 + 5` 는 "지금 점수에 5를 더한 값을 다시 점수에 넣어라"가 된다. 읽을 때 `=` 를 **"는 ~가 된다"** 로 읽으면 헷갈리지 않는다.

## 이름 짓는 규칙

변수 이름을 아무렇게나 지을 수는 없다. 두 언어가 거의 같은 규칙을 쓴다.

  rows={[
    ['글자·숫자·밑줄만 쓴다', '<code>score</code>, <code>score2</code>, <code>my_score</code>', '<code>my-score</code>, <code>score!</code>'],
    ['숫자로 시작할 수 없다', '<code>score1</code>, <code>c1</code>', '<code>1반</code>, <code>2nd</code>'],

    ['예약어를 쓸 수 없다', '<code>my_if</code>, <code>total</code>', '<code>if</code>, <code>for</code>, <code>int</code>'],
    ['대소문자를 구분한다', '<code>score</code> 와 <code>Score</code> 는 다른 변수', '—'],
  ]}
/>

Python은 한글 이름도 쓸 수 있어 이 교과서의 Python 예제에서 더러 쓴다. C는 표준으로는 쓸 수 없다.

<InfoBox variant="warn" label="규칙을 어기면 어떤 오류가 나는가">
`1반 = [88, 92, 75]` 라고 적고 실행하면 Python은 이렇게 알려 준다.

```text
    1반 = [88, 92, 75]
     ^
SyntaxError: invalid syntax
```

**화살표가 가리키는 곳**을 보자. `1` 다음의 `반` 에서 걸렸다. 숫자로 시작하는 이름을 만들 수 없기 때문이다. 오류 메시지는 무엇이 잘못됐는지보다 **어디서 걸렸는지**를 먼저 알려 준다. 이 차시의 활동에서 여러 가지를 직접 어겨 볼 것이다.
</InfoBox>

## 값이 바뀌지 않는 것 — 상수

원주율처럼 프로그램이 도는 동안 **바뀌면 안 되는 값**이 있다. 이런 값을 <Term ko="상수" en="constant" desc="한 번 정하면 프로그램이 도는 동안 바뀌지 않는 값" />라 한다.

- C는 `const double PI = 3.14159;` 처럼 `const` 를 붙여 언어가 막아 준다. 바꾸려 하면 컴파일 오류가 난다.
- Python에는 막아 주는 장치가 없다. 대신 `PI = 3.14159` 처럼 **이름을 모두 대문자로 적어** "이건 바꾸지 말자"고 약속한다.

<InfoBox variant="info" label="언어가 막아 주는 것과 사람이 지키는 것">
1단원 2차시에서 다룬 차이가 여기서도 나타난다. C는 컴파일 단계에서 막고, Python은 사람이 지킨다. **자기가 쓰는 언어가 무엇을 대신 막아 주고 무엇을 안 막아 주는지** 알아 두면, 안 막아 주는 쪽은 스스로 조심하면 된다.
</InfoBox>

## 더 알아보기

<MoreBox tag="심화" title="변수는 상자인가, 이름표인가">
"변수는 값을 담는 상자"라는 비유는 C에 잘 맞는다. `int score = 88;` 은 실제로 메모리에 정수 한 칸을 잡고 88을 써 넣는다. 그런데 Python은 조금 다르다. `점수 = 88` 은 88이라는 값에 **이름표를 붙이는** 쪽에 가깝다. 그래서 `a = [1, 2]` 뒤에 `b = a` 를 하면, 상자가 복사되는 것이 아니라 같은 목록에 이름표가 하나 더 붙는다. 이 차이는 4차시에서 리스트를 다룰 때 실제로 겪게 된다. 지금은 **비유는 언어마다 잘 맞는 곳이 다르다**는 것만 기억해 두자.
</MoreBox>

<MoreBox tag="실무" title="이름 짓는 방식을 팀에서 통일한다">
여러 단어를 이어 붙일 때 방식이 여럿이다. `total_sum` 처럼 밑줄로 잇는 방식, `totalSum` 처럼 뒷 단어 첫 글자를 대문자로 쓰는 방식이 대표적이다. 어느 쪽이 옳다기보다 **한 프로그램 안에서 섞이지 않는 것**이 중요하다. Python에서는 밑줄 방식이, Java나 JavaScript에서는 대문자 방식이 관례로 굳어 있다. 3단원 5차시에서 모둠의 코딩 규칙을 정할 때 이 항목이 들어간다.
</MoreBox>

<MoreBox tag="심화" title="선언하고 쓰는 언어, 그냥 쓰는 언어">
C는 `int score;` 처럼 **미리 알려야** 쓸 수 있다. 알리지 않고 쓰면 컴파일 오류다. Python은 값을 넣는 순간 변수가 생긴다. 편하지만 대가가 있다 — `점수` 를 `점슈` 로 잘못 적어도 새 변수가 조용히 만들어진다. C라면 "그런 이름 없다"고 바로 걸렸을 일이 Python에서는 실행 중에 엉뚱한 결과로 나타난다. 1단원 2차시의 "오류를 만나는 시점" 차이가 변수 이름에서도 그대로 나타나는 셈이다.
</MoreBox>
