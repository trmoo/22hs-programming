## 생각 열기 — 변수 서른 개

반 학생 서른 명의 점수를 다뤄야 한다. 지금까지 배운 것으로 하면 이렇게 된다.

```text
점수1 = 88
점수2 = 92
점수3 = 75
...
점수30 = 64
```

합계를 구하려면 `점수1 + 점수2 + ... + 점수30` 을 손으로 적어야 한다. 학생이 한 명 늘면 코드를 또 고쳐야 한다.

<InfoBox variant="think" label="함께 생각해 보기">
이름이 `점수1`, `점수2` 처럼 **번호만 다르다는 점**을 보자. 이름 하나에 번호를 붙여 가리킬 수 있다면 어떨까? 그리고 그렇게 되면 1단원 7차시에서 배운 **반복**과 어떻게 이어질까?
</InfoBox>

## 리스트와 배열 — 값을 줄지어 담는다

여러 값을 하나의 이름으로 묶어 순서대로 담은 것을 Python에서는 <Term ko="리스트" en="list" desc="여러 값을 순서대로 담은 자료. 크기를 바꿀 수 있다" />, C에서는 <Term ko="배열" en="array" desc="같은 자료형의 값을 정해진 개수만큼 이어서 담은 자료" />이라 한다.

3차시의 문자열처럼 **인덱스로 꺼낸다. 0번부터 센다.**

<CodeSample lang="python" caption="리스트 만들고 다루기" expect={"개수: 5\n첫째: 88 / 마지막: 64\n합계: 419\n평균: 83.8\n최고: 100\n하나 넣은 뒤: [88, 92, 75, 100, 64, 70]\n"}>
{`점수 = [88, 92, 75, 100, 64]
print("개수:", len(점수))
print("첫째:", 점수[0], "/ 마지막:", 점수[-1])
print("합계:", sum(점수))
print("평균:", sum(점수) / len(점수))
print("최고:", max(점수))

점수.append(70)
print("하나 넣은 뒤:", 점수)`}
</CodeSample>

<CodeSample lang="c" caption="배열 만들고 다루기" expect={"개수: 5\n첫째: 88 / 마지막: 64\n합계: 419\n평균: 83.8\n최고: 100\n"}>
{`#include <stdio.h>

int main(void)
{
    int scores[5] = {88, 92, 75, 100, 64};
    int n = 5;
    int sum = 0, high = scores[0];

    for (int i = 0; i < n; i++) {
        sum += scores[i];
        if (scores[i] > high) high = scores[i];
    }
    printf("개수: %d\\n", n);
    printf("첫째: %d / 마지막: %d\\n", scores[0], scores[n - 1]);
    printf("합계: %d\\n", sum);
    printf("평균: %.1f\\n", (double)sum / n);
    printf("최고: %d\\n", high);
    return 0;
}`}
</CodeSample>

## 두 코드의 길이가 다른 까닭

같은 일을 하는데 C 쪽이 길다. 언어가 대신 해 주는 일이 다르기 때문이다.

<CompareTable
  caption="리스트와 배열의 차이"
  headers={['', 'Python 리스트', 'C 배열']}
  rows={[
    ['크기', '늘었다 줄었다 한다', '만들 때 정하면 <strong>바뀌지 않는다</strong>'],
    ['담는 값', '종류가 섞여도 된다', '같은 자료형만'],
    ['개수 알기', '<code>len(점수)</code>', '자기 길이를 모른다 — <strong>개수를 따로 들고 다닌다</strong>'],
    ['합계·최댓값', '<code>sum()</code>, <code>max()</code> 가 있다', '반복문으로 직접 구한다'],
    ['하나 더 넣기', '<code>append()</code>', '자리가 남아 있어야 하고 개수도 손으로 늘린다'],
  ]}
/>

**C 코드에서 `int n = 5;` 를 따로 들고 다니는 것**을 눈여겨보자. 배열은 자기 길이를 모르므로, 개수를 잃어버리면 어디까지가 값인지 알 수 없다. 3단원 5차시에서 `average(scores, 5, &avg)` 처럼 개수를 함께 넘긴 것이 이 때문이다.

<InfoBox variant="warn" label="배열 범위를 넘어가면">
`scores[5]` 는 없는 자리다(0~4까지만 있다). Python이라면 `IndexError` 로 바로 알려 주지만, **C는 그냥 옆 메모리를 읽는다.** 오류도 없이 엉뚱한 값이 나오거나, 쓰기까지 하면 다른 변수를 망가뜨린다. C에서 배열을 다룰 때 반복 조건을 `i < n` 으로 적는지(`i <= n` 이 아니라) 늘 확인해야 하는 이유다.
</InfoBox>

## 반복과 만나면 힘이 생긴다

리스트의 진짜 쓸모는 **반복문과 만날 때** 나온다. 학생이 30명이든 300명이든 코드가 그대로다.

```text
합계 ← 0
점수 목록의 각 점수에 대하여 되풀이한다
    합계 ← 합계 + 점수
평균 ← 합계 ÷ 개수
```

1단원 7차시에서 그린 이 의사 코드가 위 C 예제의 `for` 문 그대로다. 반복은 10차시에서 본격적으로 다룬다.

## 더 알아보기

<MoreBox tag="심화" title="리스트를 복사한다는 것">
1차시의 「더 알아보기」에서 Python 변수는 이름표에 가깝다고 했다. 그 차이가 리스트에서 실제 문제로 나타난다.

```text
a = [1, 2, 3]
b = a
b.append(4)
print(a)      # [1, 2, 3, 4]
```

`b` 를 고쳤는데 `a` 도 바뀐다. 상자를 복사한 것이 아니라 **같은 리스트에 이름표를 하나 더 붙인** 것이기 때문이다. 진짜로 복사하려면 `b = a[:]` 처럼 잘라 내기로 새 리스트를 만들어야 한다. 이 함정은 실제로 자주 걸리므로 한 번 실행해 보는 것이 좋다.
</MoreBox>

<MoreBox tag="심화" title="값이 메모리에 이어져 있다는 뜻">
배열은 값들이 메모리에 **붙어서** 놓인다. `int` 가 4바이트라면 `scores[0]` 다음 4바이트가 `scores[1]` 이다. 그래서 `scores[i]` 를 찾는 계산이 "시작 주소 + i × 4" 로 끝난다 — 몇 번째든 같은 시간에 찾는다. 이것이 인덱스로 꺼내는 일이 빠른 이유다. 반대로 중간에 값을 끼워 넣으려면 뒤의 값을 전부 한 칸씩 밀어야 해서 느리다. **자료를 어떤 모양으로 담을지가 무엇이 빠른지를 정한다** — 3단원 3차시에서 자료의 모양을 설계에 적어 둔 이유다.
</MoreBox>

<MoreBox tag="실무" title="표처럼 다루려면 — 2차원">
학생마다 여러 과목 점수를 다루려면 어떻게 할까. 리스트 안에 리스트를 넣으면 된다.

```text
점수 = [[88, 92, 75],
        [70, 80, 90]]
점수[0][1]   # 첫째 학생의 둘째 과목 → 92
```

C에서는 `int scores[2][3];` 처럼 적는다. 이렇게 두 번호로 가리키는 것을 2차원 배열이라 한다. 11차시에서 중첩 반복을 배우면 이 표를 한 칸씩 훑을 수 있게 된다.
</MoreBox>
