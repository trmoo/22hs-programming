## 생각 열기 — 구구단 전체를 찍으려면

10차시에서 3단만 찍었다. 2단부터 9단까지 전부 찍으려면 어떻게 할까.

`단` 값을 바꿔 여덟 번 실행하는 방법이 있다. 아니면 같은 `for` 문을 여덟 번 복사해 붙일 수도 있다.

<InfoBox variant="think" label="함께 생각해 보기">
"단이 2부터 9까지 바뀐다"는 것도 **되풀이**다. 그리고 각 단 안에서 "1부터 9까지"가 또 되풀이된다. **되풀이 안의 되풀이**를 어떻게 적을까? 그리고 그때 몇 번 실행되는가?
</InfoBox>

## 중첩 반복 — 안쪽이 다 돌고 나서 바깥이 한 칸

<Term ko="중첩 반복" en="nested loop" desc="반복 안에 또 다른 반복이 들어 있는 구조" />의 동작 규칙은 하나다.

> **바깥이 한 번 돌 때마다 안쪽이 처음부터 끝까지 다 돈다.**

바깥이 8번, 안쪽이 9번이면 안쪽 몸통은 8 × 9 = **72번** 실행된다.

```text
바깥 i = 1 ─┬─ 안쪽 j = 1
            ├─ 안쪽 j = 2
            └─ 안쪽 j = 3     ← 안쪽이 끝나면
바깥 i = 2 ─┬─ 안쪽 j = 1     ← 안쪽이 처음부터 다시
            ├─ 안쪽 j = 2
            └─ 안쪽 j = 3
```

## 줄바꿈이 어디 있는지가 모양을 정한다

별 찍기에서 눈여겨볼 것은 **`print()` 의 자리**다.

```text
for i in range(1, 5):
    for j in range(i):
        print("*", end="")   ← 줄바꿈 없이 이어 찍는다
    print()                  ← 안쪽 반복이 끝난 뒤 줄을 바꾼다
```

`print()` 가 **안쪽 반복 밖, 바깥 반복 안**에 있다. 이 자리를 한 칸만 옮기면 모양이 완전히 달라진다.

| `print()` 의 자리 | 결과 |
|---|---|
| 안쪽 반복 밖 (지금) | 줄마다 별이 늘어난다 |
| 안쪽 반복 **안** | 별 하나마다 줄이 바뀐다 — 한 줄에 하나씩 |
| 바깥 반복 **밖** | 별이 전부 한 줄에 붙는다 |

**들여쓰기 한 칸이 흐름을 바꾼다.** 9차시에서 Python의 들여쓰기가 문법이라고 한 것이 여기서 실감된다.

<InfoBox variant="tip" label="안쪽 반복 횟수가 바깥 변수에 걸려 있다">
`for j in range(i)` 를 보자. 안쪽이 도는 횟수가 **바깥 변수 `i` 에 따라 바뀐다.** `i` 가 1일 때 1번, 2일 때 2번이다. 그래서 별이 삼각형으로 늘어난다.

안쪽 횟수를 고정하면(`range(4)`) 직사각형이 된다. **삼각형과 직사각형의 차이가 이 한 곳에서 갈린다.**
</InfoBox>

## 반복 안의 선택 — 걸러 내기

대각선 표는 반복 안에 조건이 들어간 예다.

```text
for i in range(1, 4):
    for j in range(1, 4):
        if i == j:        ← 행 번호와 열 번호가 같은 자리
            print("O", ...)
        else:
            print(".", ...)
```

`i == j` 인 자리가 대각선이다. 3단원 6차시의 `summarize` 에서 반복 안에 `if is_valid(...)` 를 넣어 범위 밖 값을 걸러 낸 것과 같은 얼개다.

## C의 `조건 ? A : B`

C 예제에 `i == j ? "O" : "."` 라는 표기가 나온다. **조건이 참이면 A, 거짓이면 B** 를 값으로 내놓는 짧은 표기다. `if / else` 를 한 줄로 줄인 것이다.

Python에도 비슷한 표기가 있다 — `"O" if i == j else "."`.

<InfoBox variant="info" label="짧게 쓰는 것이 늘 좋은 것은 아니다">
값 하나를 고르는 정도면 이 표기가 읽기 좋다. 그런데 조건 안에 또 조건을 넣어 겹치기 시작하면 금방 읽을 수 없게 된다. **한 줄에 담을 수 있다는 것이 담아야 한다는 뜻은 아니다.** 갈래마다 할 일이 여러 줄이면 `if / else` 로 펴서 적는다.
</InfoBox>

## 흐름을 손으로 짚는다

중첩이 들어가면 머릿속으로 따라가기 어렵다. 3단원 4차시의 **책상 검사**를 쓴다. 변수마다 칸을 만들어 한 회차씩 적는다.

별 찍기의 처음 세 회차를 짚어 보자.

| 바깥 `i` | 안쪽 `j` 가 도는 횟수 | 이 줄에 찍히는 것 | 줄바꿈 |
|---|---|---|---|
| 1 | 1번 (j = 0) | `*` | 있음 |
| 2 | 2번 (j = 0, 1) | `**` | 있음 |
| 3 | 3번 (j = 0, 1, 2) | `***` | 있음 |
| 4 | 4번 | `****` | 있음 |

**안쪽 반복의 횟수 칸이 핵심이다.** 이 칸이 `i` 에 따라 늘어나는 것을 눈으로 확인하면 삼각형이 나오는 이유가 보인다.

## 더 알아보기

<MoreBox tag="심화" title="바깥 반복을 끊으려면">
중첩 안에서 `break` 를 쓰면 **안쪽 반복만** 끊긴다. 바깥까지 한 번에 빠져나가는 문법은 두 언어에 없다. 방법은 두 가지다. 표시 변수를 하나 두어 바깥 조건에 넣거나, **그 부분을 함수로 떼어 내 `return` 으로 빠져나가는** 것이다.

뒤의 방법이 대체로 깔끔하다. 16차시에서 함수로 프로그램을 나누는 것을 배우면 이 방법을 쓸 수 있다. 중첩이 깊어 빠져나가기 어려워졌다는 것은 **그 부분이 따로 떼어 낼 만한 일**이라는 신호이기도 하다.
</MoreBox>

<MoreBox tag="심화" title="2차원 표를 다루기">
4차시 「더 알아보기」에서 리스트 안의 리스트를 잠깐 봤다. 중첩 반복이 그 표를 훑는 도구다.

```text
점수 = [[88, 92, 75],
        [70, 80, 90]]

for 학생 in 점수:          ← 행마다
    for 과목점수 in 학생:   ← 그 행의 칸마다
        print(과목점수, end=" ")
    print()
```

바깥이 행, 안쪽이 열이다. C에서는 `scores[i][j]` 처럼 번호 두 개로 가리킨다. 학생별 평균은 바깥 반복 안에서, 과목별 평균은 반복 순서를 바꿔서 구한다. **표를 어느 방향으로 훑을지가 무엇을 구할지 정한다.**
</MoreBox>

<MoreBox tag="실무" title="중첩이 깊어지면 느려진다">
바깥 100번, 안쪽 100번이면 몸통이 1만 번 실행된다. 세 겹이면 100만 번이다. 자료가 100개일 때는 눈에 안 띄지만 10,000개가 되면 1억 번이 된다.

1단원 6차시에서 다룬 효율 이야기가 이 자리에서 실제 문제가 된다. 중첩을 세 겹 넘게 쓰고 있다면 **정말 모든 짝을 봐야 하는지** 다시 생각해 볼 만하다. 대개는 한 번만 훑으면서 필요한 것을 모아 두는 방법이 있다 — 3단원 4차시 「더 알아보기」에서 인원·합계·최고·최저를 한 번에 구한 것이 그 예다.
</MoreBox>
